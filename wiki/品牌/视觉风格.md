# Kairos 视觉风格

> 方向：**BGB 白皮书的 3D 质感** + **币安金**（用户确认）。参考件：`raw/参考/Pitch Deck/BGB-whitepaper-en-20241227.pdf`。

## 总基调
纯黑底、写实 **3D 玻璃 + 金属**主体、**彩散/虹彩高光**、单一亮色点缀、粗体无衬线字。
**关键替换：把 BGB 的 cyan 换成币安金黄。**

## 配色
| 角色 | 色值 | 用途 |
|---|---|---|
| 主色 · 币安金 | `#F0B90B` | logo、强调、关键数字、链接 |
| 亮金高光 | `#FCD535` | 渐变高光、3D 反光 |
| 深金阴影 | `#B8860B` | 金属暗部过渡 |
| 底色 · 纯黑 | `#0B0B0B` | 主背景 |
| 卡片灰 | `#1A1A1A` | 数据卡/分区 |
| 文字 · 白 | `#FFFFFF` / `#B5B5B5` | 标题 / 正文次级 |

> 金色金属渐变建议：`#FCD535 → #F0B90B → #B8860B`（顶高光→中→暗）。

## 字体
- 标题：粗体无衬线（**Geist / Space Grotesk / Inter** 任一，全大写或重字重）。
- 正文：Inter / 思源黑体（中文）。

## 3D 物料规范（出图/出素材统一）
- 材质：透明玻璃（含彩色色散/虹彩边缘）+ 抛光金属金。
- 打光：黑底、强反差、边缘高光、轻微镜面反射地面。
- 主体悬浮、带景深；点缀小球/碎片用币安金。
- 版式骨架沿用 BGB（左上页码进度条、大标题、深色数据卡），**配色换金**。

## Logo
- 概念与产出见 `logo/`（由 `tools/gen_logo.py` 用 Gemini 生成；扁平矢量由 `tools/gen_logo_sunrise.py` 生成）。
- 符号方向：① 沙漏（kairos=时机）；② 「K」3D 金币/代币；③ 额前发绺/疾风（典故见 [[命名方案]]）；④ **旭日/放射光芒 ← 选定主 mark（扁平，见下）**。

### 旭日 Sunrise（复刻参考图 `raw/参考/logoReferences/2.png`）
母题：**地平线 + 半圆太阳 + 向上放射尖刺**（sunburst），象征「破晓 / 抓住关键时刻」。
去掉参考图的 "maka" 文字，配色由纯白改为**币安金**，**只要图标、透明底、扁平不做金属**（用户定）。

- **扁平矢量（选定主 mark）**：`tools/gen_logo_sunrise.py` 纯标准库参数化生成。
  - 定版参数（变体 C，最贴近参考 `raw/参考/logoReferences/1.png`）：`--flat --rays 21 --ray-half-w 2.6`，**纯色平涂 `#F0B90B`**。
  - 资产：`logo/sunrise_flat.svg` + `logo/sunrise_flat_{2048,512,256,64}.png`（**RGBA 透明底**）。
  - 几何参数化：尖刺数、太阳半径、尖刺内外半径/角宽、扇形跨角、地平线粗细均可调，秒级重出。
  - 备选 `--gradient`：金色纵向渐变 `#FCD535 → #F0B90B → #B8860B`（2D 层次、非金属）。
  - 栅格器：`rsvg-convert`（librsvg，主），`cairosvg`（pip，回退）。
- **3D 金属版**：暂不采用（用户要扁平、不要金属）。脚本路径仍保留在 `tools/gen_logo.py --only sunrise --ref <参考图> --transparent`，将来需要大图主视觉时可再出。

# Kairos 视觉风格

> 方向：**BGB 白皮书的 3D 质感** + **币安金**（用户确认）。参考件：`raw/参考/Pitch Deck/BGB-whitepaper-en-20241227.pdf`。

## 总基调
纯黑底、写实 **3D 玻璃 + 金属**主体、**彩散/虹彩高光**、单一亮色点缀、粗体无衬线字。
**关键替换：把 BGB 的 cyan 换成币安金黄。**

## 配色
| 角色 | 色值 | 用途 |
|---|---|---|
| 主色 · 币安金 | `#F0B90B` | logo、强调、关键数字、链接 |
| 亮金高光 | `#FCD535` | 渐变高光、3D 反光 |
| 深金阴影 | `#B8860B` | 金属暗部过渡 |
| 底色 · 纯黑 | `#0B0B0B` | 主背景 |
| 卡片灰 | `#1A1A1A` | 数据卡/分区 |
| 文字 · 白 | `#FFFFFF` / `#B5B5B5` | 标题 / 正文次级 |

> 金色金属渐变建议：`#FCD535 → #F0B90B → #B8860B`（顶高光→中→暗）。

## 字体
- 标题：粗体无衬线（**Geist / Space Grotesk / Inter** 任一，全大写或重字重）。
- 正文：Inter / 思源黑体（中文）。

## 3D 物料规范（出图/出素材统一）
- 材质：透明玻璃（含彩色色散/虹彩边缘）+ 抛光金属金。
- 打光：黑底、强反差、边缘高光、轻微镜面反射地面。
- 主体悬浮、带景深；点缀小球/碎片用币安金。
- 版式骨架沿用 BGB（左上页码进度条、大标题、深色数据卡），**配色换金**。
